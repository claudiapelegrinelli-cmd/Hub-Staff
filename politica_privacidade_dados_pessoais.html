Política de Privacidade e Proteção de Dados Pessoais

Classificação: Público

Objetivo

Este documento tem por objetivo estabelecer diretrizes de proteção e privacidade dos dados pessoais, conforme estabelecido pela Lei Geral de Proteção de Dados Pessoais - LGPD 13.709/2018.

Definição do Escopo

Aplica-se a todas as áreas da WeClever, abrangendo todos os colaboradores e prestadores de serviço.

Dos Dados Pessoais

Informações Gerais

O compromisso da WeClever é garantir a proteção dos dados e informações pessoais das quais somos controladores, bem como os dados pessoais que recebemos dos nossos clientes através dos leads, os quais atuamos como operadores.

Dados coletados e finalidade do tratamento

WeClever — Controlador

A WeClever, como "Controlador" de dados pessoais, garante o tratamento e finalidade para os quais os dados são coletados, bem como sua proteção sob estrita confidencialidade.

Os dados coletados serão utilizados para cumprir obrigações contratuais, cumprir obrigações trabalhistas e previdenciárias, tramitar seguros de saúde e de vida, como:

  • Informações pessoais — nome, foto, data de nascimento, estado civil, RG, CPF, CTPS, PIS, título de eleitor, reservista, dados bancários (agência e conta), informações educacionais;
  • Informações de contato — e-mail, telefone fixo e celular, endereço residencial.

WeClever — Operador

A WeClever, como "operador" de dados pessoais recepcionados através dos leads que recebemos dos clientes, garante o tratamento e finalidade para os quais os dados são coletados, bem como sua proteção sob estrita confidencialidade.

Os dados pessoais recebidos através de leads, que serão utilizados para ofertar o produto do cliente, são:

  • Informações pessoais — nome;
  • Informações de contato — número de telefone.

Armazenamento dos Dados Pessoais

As informações pessoais serão mantidas durante o período que se manter a prestação de serviços ou vínculo empregatício.

As informações pessoais que processamos para qualquer propósito não deverão ser mantidas por mais tempo do que o necessário para tal propósito.

Os dados serão eliminados com o fim da utilização dos nossos serviços ou a pedido expresso do titular, sendo mantidos por tempo superior nos casos descritos em lei, enquanto perdurar o prazo legal.

Na transferência de leads feita para a WeClever, em decorrência da localização de sua infraestrutura de cloud computing estar localizada em território internacional (Virgínia - EUA), será necessário transportar esses leads de território nacional para território internacional, uma vez que os leads serão capturados em seu país de origem.

Tratamento de Dados Pessoais

O titular ou o cliente controlador dos dados pessoais podem, a qualquer tempo:

  • Confirmar a existência do tratamento de seus dados;
  • Acessar os dados armazenados;
  • Solicitar correções de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados;
  • Realizar a portabilidade de seus dados a outro fornecedor de serviço ou produto, mediante requisição expressa e formal, observados os sigilos pessoais;
  • Eliminação dos dados pessoais;
  • Revogar o consentimento sobre os dados a serem armazenados na plataforma.

Expurgo de Dados Pessoais

A WeClever faz o expurgo de dados pessoais após o término do contrato com o cliente, através de API interna de deleção de dados.

O descarte dos dados pessoais ou anonimização também ocorre quando solicitado pelo controlador de dados ou pelo titular dos mesmos.
